## 📊 Dataset Overview

- **Rows:** 4,803 movies
- **Columns:** 24 (before cleaning)
- **Duplicate rows:** 0

Key columns include:

| Column | Meaning |
|--------|---------|
| `budget`, `revenue` | Production budget and box-office revenue |
| `genres`, `keywords` | Genre labels and descriptive keywords |
| `original_title`, `title`, `overview`, `tagline` | Title and text descriptions |
| `release_date`, `runtime` | Release date and length in minutes |
| `popularity`, `vote_average`, `vote_count` | Audience metrics |
| `production_companies`, `production_countries`, `spoken_languages` | Production details |
| `cast`, `crew`, `director` | People involved |

**Missing values found:** `homepage` (3,091), `keywords` (412), `genres` (28), `overview` (3), `release_date` (1), and a few others.

## 🔍 What the Notebook Does

1. **Load data**: reads `movies.csv` directly from a zip file using `zipfile` + `pandas`.
2. **Inspect structure**: `head()`, `tail()`, `sample()`, `shape`, `info()`, `columns`, `dtypes`.
3. **Check data quality**: `isnull().sum()` for missing values and `duplicated().sum()` for duplicates.
4. **Summary statistics**: `describe()` for numeric columns and `describe(include='all')` for the full dataset.
5. **Explore columns**: `value_counts()` on genres, unique values of budget, and mean / median / mode of `id`.
6. **Row selection**: examples using `loc[]` for label-based access.
7. **Cleaning & type handling**
   - Fills missing `id` values with the mode
   - Drops the `status` column
   - Checks for duplicates with `drop_duplicates()`
   - Converts `production_countries` to the `category` dtype
8. **Export**: saves the cleaned data as `new_movies_clean.csv`.
